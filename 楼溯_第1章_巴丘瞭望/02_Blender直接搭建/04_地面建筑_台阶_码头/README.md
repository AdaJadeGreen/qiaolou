## 文件
- `地面建筑与码头_套件.blend`：场景「地面建筑与码头」。`地码套件_*` 集合为构件本体，「地码展示」「地码组装演示」为集合实例。
  组装演示从 `../营地建筑/` 和 `../城墙与栅栏/` 追加了圆帐、敞棚、旗杆、篝火灶、木栅栏。
- `fbx/`：每件一个 FBX（-Z 前向、Y 上）。
- `renders/`：每件正视/侧视/顶视/透视 + 水岸鸟瞰、码头近景、台阶近景。
