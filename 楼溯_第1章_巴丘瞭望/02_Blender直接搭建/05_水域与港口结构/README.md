# 水域与港口结构 · 模块化套件（Blender 直接搭建）

由 `harbor_kit.py` 生成（复用 `../地面建筑与码头/ground_kit.py` 的石作、木作函数，两个脚本需保持在原位置）。
单位米；正面朝 -Y；**原点 z=0 为水面**，岸面/堤顶 1.2 m，与地面建筑与码头套件一致。

| H02 | 防波堤端头·烽火台 | 12.5 × 10.6 × 11.5 | 2.8k | 半径 4 m 圆形石台 + 抛石；木构烽火台（平台、火盆、竖梯、信号旗） |

## 文件
- `水域与港口结构_套件.blend`：场景「水域与港口结构」。`港口套件_*` 为构件本体；「港口展示」「港口组装演示」为集合实例。
  港湾演示追加了 `地面建筑与码头`（岸壁、栈桥、端头平台、系船桩、石板路）和 `营地建筑`（营房、敞棚、旗杆）。
- `fbx/`：每件一个 FBX；`renders/`：每件正视/侧视/顶视/透视 + 港湾鸟瞰、水门近景、防波堤与烽火台、修船滑道。
