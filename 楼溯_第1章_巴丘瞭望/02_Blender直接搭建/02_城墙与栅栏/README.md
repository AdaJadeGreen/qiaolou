# 城墙与栅栏 · 模块化套件（Blender 直接搭建）

由 `wall_kit.py` 生成，在 Blender 中运行即可重建（Scripting 控制台 `exec` 或 `blender -b -P wall_kit.py`）。

## 文件
- `城墙与栅栏_套件.blend`：场景「城墙与栅栏」。`套件_*` 集合是构件本体（视图层中排除），「展示」「组装演示」用集合实例引用，改构件会同步到所有实例。
- `fbx/`：每个构件一个 FBX（-Z 前向、Y 上，可直接进 Unity）。
- `renders/`：每个构件正视/侧视/顶视/透视 + 组装鸟瞰、城门近景。
- `wall_kit.py` 顶部参数：`WALL_H`（墙高）、`WALL_T0/T1`（底/顶厚）、`SEG_L`（段长）、`PAL_H`（女墙高）、`SEED`（改变毛石排布）。
