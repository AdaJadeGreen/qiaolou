# 《楼·溯》第1章·巴丘瞭望 —— 3D 资产（上传版）

岳阳楼时间回溯 3D 解谜游戏，第 1 章「巴丘瞭望」（鲁肃时期）。
Blender 5.3 制作，单位米，+Z 向上。所有 .blend 已内嵌贴图，下载解压后直接打开即可查看、编辑。

## 总场景大纲层级

- **01_Blender直接搭建**
  - 01_瞭望楼主体：建成后显示；建立中、废墟在同一位置隐藏（眼睛图标切换）
  - 02_城墙与栅栏 · 03_营地建筑 · 04_地面建筑_台阶_码头 · 05_水域与港口结构
  - 06_主角_鲁肃：鲁肃 v3，站在瞭望楼台阶前
- **02_Tripo生成_占位**：01_船只 … 08_场景小道具，实例名就是资产编号（如 `CH01-SHP-02_占位`）
- **03_地形与水面** · **04_相机**（7 个机位）
- **_资产源_套件(不渲染)**：所有实例的源集合。Tripo 模型生成后，放进 `_源_Tripo占位原型/<编号>_占位` 替换网格，场景里所有同编号实例自动更新。
